# 화면 목록 — 문자의 사용과 식의 값

모듈 6개, 화면 20개, 영상 3개

차시 유형: 개념 중심 차시 (10분 안팎) · 새 어휘 2개, 초등에서 배운 말 안내 1개

## 이 차시의 어휘

| 부류 | 낱말 |
|---|---|
| 새 어휘 = 핵심 개념어 (이 차시에서 익힘) | 대입, 식의 값 |
| 초등에서 배운 말 (이 차시 안에서 배경지식으로 안내) | 식 (초3-1) |
| 수행 도구어 (문제에서 쓰는 말) | 구하다 → 1차시, 나타내다 → 2차시 |
| 공기관계어 | ~에 ~을/를 대입하다, ~일 때, ~의 값을 구하시오, 식의 값을 구하시오, 문자를 사용한 식으로 나타내시오, 곱셈 기호를 생략하다 |
