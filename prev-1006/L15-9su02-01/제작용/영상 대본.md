# 영상 대본 — 문자의 사용과 식의 값

중학교 1학년 · [9수02-01] 다양한 상황을 문자를 사용한 식으로 나타내어 그 유용성을 인식하고, 식의 값을 구할 수 있다.

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 교과서에서 만난 낱말

위치: 2. 어휘 제시 · 화면 2

메모: 새 낱말을 수업 장면 속에서 처음 보여 준다. 이미 아는 말과 이미 아는 개념에서 출발한다는 점을 대사로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  | 아미르: 식에 글자 x가 있어!<br>유나: x 자리에 수를 넣어서 계산하면 돼. |  |  | 교과서 문제를 크게 보여 준다 |
| 2 | 그림(시안 참조) | 아미르: 아, 수를 넣는 것! 해 본 적 있어.<br>유나: 그걸 한국어로 **대입**이라고 해. |  |  | x 자리에 2가 들어간다 |

## 영상 2. 낱말 풀이: 식에서 대입과 식의 값까지

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 | 그림(시안 참조) |  | 수 대신 문자 x를 써서 식으로 나타낼 수 있어요. | 수 대신 문자 엑스를 써서 식으로 나타낼 수 있어요. | 초등에서 배운 말 ‘식’에서 시작한다 |
| 2 | 그림(시안 참조) |  | 곱셈 기호 ×는 생략해요. ‘생략’은 ‘쓰지 않는다’는 뜻이에요. | 곱셈 기호는 생략해요. 생략은 쓰지 않는다는 뜻이에요. |  |
| 3 | 그림(시안 참조) |  | 문자 대신 수를 넣는 것을 ‘**대입**’이라고 해요. ‘x에 2를 대입한다’고 말해요. | 문자 대신 수를 넣는 것을 대입이라고 해요. 엑스에 이를 대입한다고 말해요. |  |
| 4 | 그림(시안 참조) |  | 대입해서 계산한 결과 7을 ‘**식의 값**’이라고 해요. | 대입해서 계산한 결과 칠을 식의 값이라고 해요. |  |

## 영상 3. 교과서 문장 속의 낱말

위치: 4. 용례 · 화면 1

메모: 용례 단계. 학교 수업에서 실제로 만나는 교과서 문장을 보여 주고, 함께 쓰이는 말(공기관계어)과 수행 도구어를 자막으로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  |  | ‘~일 때, ~의 값을 구하시오’는 대입해서 계산하라는 말이에요. | ~일 때, ~의 값을 구하시오는 대입해서 계산하라는 말이에요. |  |
| 2 |  |  | ‘~에 ~을/를 대입하다’로 써요. | ~에 ~을/를 대입하다로 써요. |  |
| 3 |  |  | 말로 된 내용을 x, a 같은 문자를 써서 식으로 바꾸라는 말이에요. | 말로 된 내용을 x, a 같은 문자를 써서 식으로 바꾸라는 말이에요. |  |
| 4 |  |  | 음수를 대입할 때는 괄호를 써요. 3a → 3 × (−2) | 음수를 대입할 때는 괄호를 써요. 3a → 3 × (−2) |  |
