# 화면 목록 — 최대공약수와 최소공배수

모듈 6개, 화면 24개, 영상 3개

차시 유형: 개념 중심 차시 (10분 안팎) · 새 어휘 3개, 앞에서 배운 말 확인 2개, 초등에서 배운 말 안내 4개

## 이 차시의 어휘

| 부류 | 낱말 |
|---|---|
| 새 어휘 = 핵심 개념어 (이 차시에서 익힘) | 최대공약수 (충남대 핵심어), 최소공배수 (충남대 핵심어), 서로소 |
| 앞에서 배운 말 (뜻 확인 → 모르면 그 차시로 안내) | 소인수분해 → 8차시 ‘소인수분해’, 지수 → 7차시 ‘밑과 지수’ |
| 초등에서 배운 말 (이 차시 안에서 배경지식으로 안내) | 공약수 (초5-1), 공배수 (초5-1), 약수 (초5-1), 배수 (초5-1) |
| 수행 도구어 (문제에서 쓰는 말) | 구하다 → 1차시 |
| 공기관계어 | ~과/와 ~의 최대공약수, 최대공약수를 구하시오, 최소공배수를 구하시오, 소인수분해를 이용하여, ~과/와 ~은/는 서로소이다 |
