# 영상 대본 — 양수와 음수

중학교 1학년 · [9수01-03] 다양한 상황을 이용하여 음수의 필요성을 인식하고, 양수와 음수, 정수와 유리수의 개념을 이해한다.

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 교과서에서 만난 낱말

위치: 2. 어휘 제시 · 화면 2

메모: 새 낱말을 수업 장면 속에서 처음 보여 준다. 이미 아는 말과 이미 아는 개념에서 출발한다는 점을 대사로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  | 아미르: 숫자 앞에 +, −가 있네. 더하기, 빼기야?<br>유나: 여기서는 계산이 아니야. 수의 종류를 알려 주는 **부호**야. |  |  | 온도계 그림과 함께 교과서 문장을 보여 준다 |
| 2 | 그림(시안 참조) | 아미르: 0보다 작은 수! 우리 나라에서도 배웠어.<br>유나: 한국어로는 **음수**라고 해. |  |  | 수직선 위에 수가 차례로 나타난다 |

## 영상 2. 낱말 풀이: 영상과 영하에서 양수와 음수까지

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 | 그림(시안 참조) |  | 0보다 높은 온도는 +, 0보다 낮은 온도는 −를 붙여서 나타내요. | 영보다 높은 온도는 플러스, 영보다 낮은 온도는 마이너스를 붙여서 나타내요. | 학생이 아는 상황(온도)에서 시작한다 |
| 2 | 그림(시안 참조) |  | +를 ‘**양의 부호**’, −를 ‘**음의 부호**’라고 해요. | 플러스를 양의 부호, 마이너스를 음의 부호라고 해요. |  |
| 3 | 그림(시안 참조) |  | 0보다 큰 수를 ‘**양수**’라고 해요. 양의 부호 +를 붙여요. | 영보다 큰 수를 양수라고 해요. 양의 부호 플러스를 붙여요. | 수직선의 오른쪽 수에 색이 들어온다 |
| 4 | 그림(시안 참조) |  | 0보다 작은 수를 ‘**음수**’라고 해요. 음의 부호 −를 붙여요. | 영보다 작은 수를 음수라고 해요. 음의 부호 마이너스를 붙여요. | 수직선의 왼쪽 수에 색이 들어온다 |
| 5 | 그림(시안 참조) |  | 0은 양수도 아니고 음수도 아니에요. | 영은 양수도 아니고 음수도 아니에요. |  |

## 영상 3. 교과서 문장 속의 낱말

위치: 4. 용례 · 화면 1

메모: 용례 단계. 학교 수업에서 실제로 만나는 교과서 문장을 보여 주고, 함께 쓰이는 말(공기관계어)과 수행 도구어를 자막으로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  |  | +나 −를 붙여서 쓰라는 말이에요. | +나 −를 붙여서 쓰라는 말이에요. |  |
| 2 |  |  | 서로 반대인 것을 +와 −로 나타내요. ‘증가’는 늘어남, ‘감소’는 줄어듦이에요. | 서로 반대인 것을 +와 −로 나타내요. 증가는 늘어남, 감소는 줄어듦이에요. |  |
| 3 |  |  | ‘음수를 모두 고르시오’는 0보다 작은 수를 전부 고르라는 말이에요. | 음수를 모두 고르시오는 0보다 작은 수를 전부 고르라는 말이에요. |  |
| 4 |  |  | ‘~은/는 양수이다’, ‘~은/는 음수이다’로 말해요. | ~은/는 양수이다, ~은/는 음수이다로 말해요. |  |
