낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 교과서에서 만난 낱말

위치: 2. 어휘 제시 · 화면 2

메모: 새 낱말을 수업 장면 속에서 처음 보여 준다. 이미 아는 말과 이미 아는 개념에서 출발한다는 점을 대사로 짚는다.

| 2 | 그림(시안 참조) | 아미르: 아, 이 이름! 우리 나라에서도 배웠어.<br>유나: 맞아. 한국어 이름을 익혀 보자. |  |  | 밑과 지수에 이름표가 붙는다 |

## 영상 2. 낱말 풀이: 거듭제곱에서 밑과 지수까지

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 | 그림(시안 참조) |  | 거듭제곱 2³에서 2는 곱하는 수, 3은 곱한 횟수예요. | 거듭제곱 이의 세제곱에서 이는 곱하는 수, 삼은 곱한 횟수예요. | 앞에서 배운 말 ‘거듭제곱’에서 시작한다 |
| 2 | 그림(시안 참조) |  | 곱하는 수 2를 ‘**밑**’이라고 해요. ‘밑’은 ‘아래’라는 뜻이에요. 아래에 크게 써요. | 곱하는 수 2를 밑이라고 해요. 밑은 아래라는 뜻이에요. 아래에 크게 써요. | 밑 2가 반짝인다 |
| 3 | 그림(시안 참조) |  | 곱한 횟수 3을 ‘**지수**’라고 해요. 오른쪽 위에 작게 써요. | 곱한 횟수 3을 지수라고 해요. 오른쪽 위에 작게 써요. | 지수 3이 반짝인다 |
| 4 | 그림(시안 참조) |  | 5²의 밑은 5, 지수는 2예요. | 오의 제곱의 밑은 오, 지수는 이예요. |  |
| 5 | 그림(시안 참조) |  | 밑과 지수의 자리가 바뀌면 다른 수가 돼요. | 밑과 지수의 자리가 바뀌면 다른 수가 돼요. |  |
