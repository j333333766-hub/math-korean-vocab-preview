# 영상 대본 — 절댓값과 대소 관계

중학교 1학년 · [9수01-04] 정수와 유리수의 대소 관계를 판단할 수 있다.

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

위치: 2. 어휘 제시 · 화면 2

메모: 새 낱말을 수업 장면 속에서 처음 보여 준다. 이미 아는 말과 이미 아는 개념에서 출발한다는 점을 대사로 짚는다.

## 영상 2. 낱말 풀이: 수직선에서 절댓값과 대소 관계까지

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 | 그림(시안 참조) |  | 수직선에서 0을 나타내는 점을 ‘원점’이라고 해요. | 수직선에서 영을 나타내는 점을 원점이라고 해요. | 초등에서 배운 말 ‘수직선’에서 시작한다 |
| 2 | 그림(시안 참조) |  | 원점에서 −3까지의 거리는 3이에요. 이 거리를 −3의 ‘**절댓값**’이라고 해요. | 원점에서 마이너스 삼까지의 거리는 삼이에요. 이 거리를 마이너스 삼의 절댓값이라고 해요. |  |
| 3 | 그림(시안 참조) |  | 절댓값은 기호 | |를 써서 나타내요. −3과 +3의 절댓값은 모두 3이에요. | 절댓값은 기호를 써서 나타내요. 마이너스 삼과 플러스 삼의 절댓값은 모두 삼이에요. |  |
| 4 | 그림(시안 참조) |  | 수직선에서 오른쪽에 있는 수가 더 커요. 두 수의 크고 작음을 ‘**대소 관계**’라고 해요. | 수직선에서 오른쪽에 있는 수가 더 커요. 두 수의 크고 작음을 대소 관계라고 해요. |  |
| 5 | 그림(시안 참조) |  | 대소 관계는 ‘**부등호**’ <, >로 나타내요. | 대소 관계는 부등호로 나타내요. 마이너스 이는 플러스 삼보다 작다. |  |
| 6 | 그림(시안 참조) |  | ≥, ≤도 부등호예요. ‘이상’, ‘이하’는 그 수와 같은 것도 들어가요. | 이상, 이하를 나타내는 기호도 부등호예요. 이상, 이하는 그 수와 같은 것도 들어가요. | 초등에서 배운 말 ‘이상’, ‘이하’를 부등호와 잇는다 |
