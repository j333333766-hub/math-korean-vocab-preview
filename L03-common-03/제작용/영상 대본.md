# 영상 대본 — 문제에서 쓰는 말 ③ 고르기

중학교 1~2학년 공통 · 공통 · 모든 단원의 문제에 쓰이는 말 (특정 성취기준에 속하지 않음)

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 문제의 끝말

위치: 1. 도입 · 화면 2

메모: 문제의 수학 내용은 알지만 끝말(지시어)을 몰라 멈추는 장면에서 시작한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 | 참여 활동(자막 전에 멈추고 묻기) |
|---:|---|---|---|---|---|---|
| 1 |  | 아미르: 맞는 것 하나만 고르면 될까?<br>유나: ‘**모두**’가 있으니까 맞는 것을 전부 골라야 해. |  |  | 교과서 문제를 크게 보여 준다. ‘모두’에 색이 들어온다 |  |
| 2 |  | 아미르: 이건 맞는 것을 고르는 거지?<br>유나: 아니야. 틀린 것을 골라야 해. 이 말을 잘 봐야 해. |  |  | ‘옳지 않은’에 색이 들어온다 |  |

## 영상 2. 낱말 풀이: 무엇을 하라는 말일까

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 | 참여 활동(자막 전에 멈추고 묻기) |
|---:|---|---|---|---|---|---|
| 1 |  |  | ‘**고르시오**’는 여러 개 중에서 알맞은 것을 선택하라는 말이에요. | 고르시오는 여러 개 중에서 알맞은 것을 선택하라는 말이에요. |  |  |
| 2 | 그림(시안 참조) |  | ③을 골랐어요. | ③을 골랐어요. |  |  |
| 3 |  |  | ‘**찾으시오**’는 주어진 것 속에서 알맞은 것을 찾아내라는 말이에요. | 찾으시오는 주어진 것 속에서 알맞은 것을 찾아내라는 말이에요. |  |  |
| 4 | 그림(시안 참조) |  | ‘**모두**’는 하나도 빼지 말고 전부라는 뜻이에요. 답이 여러 개일 수 있어요. | 모두는 하나도 빼지 말고 전부라는 뜻이에요. 답이 여러 개일 수 있어요. |  |  |

## 영상 3. 교과서 문장 속의 낱말

위치: 4. 용례 · 화면 1

메모: 용례 단계. 학교 수업에서 실제로 만나는 교과서 문장을 보여 주고, 함께 쓰이는 말(공기관계어)과 수행 도구어를 자막으로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 | 참여 활동(자막 전에 멈추고 묻기) |
|---:|---|---|---|---|---|---|
| 1 |  |  | ‘보기’는 고를 수 있게 준 것들이에요. ㄱ, ㄴ, ㄷ이나 ①~⑤로 나와요. | 보기는 고를 수 있게 준 것들이에요. ㄱ, ㄴ, ㄷ이나 ①~⑤로 나와요. |  |  |
| 2 |  |  | ‘옳은 것’은 맞는 것이에요. | 옳은 것은 맞는 것이에요. |  |  |
| 3 |  |  | ‘옳지 않은 것’은 틀린 것이에요. 이 말을 잘 봐야 해요. | 옳지 않은 것은 틀린 것이에요. 이 말을 잘 봐야 해요. |  |  |
| 4 |  |  | ‘차례대로’는 순서에 맞게 하나씩이라는 뜻이에요. | 차례대로는 순서에 맞게 하나씩이라는 뜻이에요. |  |  |
