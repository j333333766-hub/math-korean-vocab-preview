낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 2. 낱말 풀이: 소수에서 소인수분해까지

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 | 그림(시안 참조) |  | 1, 2, 3, 4, 6, 12는 12의 약수예요. 약수를 ‘인수’라고도 해요. | 일, 이, 삼, 사, 육, 십이는 십이의 약수예요. 약수를 인수라고도 해요. | 5차시에서 익힌 말 ‘약수’에서 시작한다. 약수 여섯 개를 모두 보여 준다 |
| 2 | 그림(시안 참조) |  | 인수 중에서 소수인 2와 3을 12의 ‘**소인수**’라고 해요. ‘소인수’는 ‘소수인 인수’예요. | 인수 중에서 소수인 이와 삼을 십이의 소인수라고 해요. 소인수는 소수인 인수예요. | 소수 2와 3에만 색이 들어온다 |
| 3 | 그림(시안 참조) |  | 12를 소인수들만의 곱으로 나타냈어요. | 십이를 소인수들만의 곱으로 나타냈어요. | 소인수 2, 2, 3에 동그라미가 차례로 생긴다 |
| 4 | 그림(시안 참조) |  | 자연수를 소인수들만의 곱으로 나타내는 것을 ‘**소인수분해**’라고 해요. ‘분해’는 ‘나누어 놓는다’는 뜻이에요. | 자연수를 소인수들만의 곱으로 나타내는 것을 소인수분해라고 해요. 분해는 나누어 놓는다는 뜻이에요. | 캐릭터가 나와서 뜻을 말한다 |
| 5 | 그림(시안 참조) |  | ‘**소인수**’는 ‘소수’와 ‘인수’를 합친 말이에요. ‘**소인수분해**’는 ‘소인수’와 ‘분해’를 합친 말이에요. | 소인수는 소수와 인수를 합친 말이에요. 소인수분해는 소인수와 분해를 합친 말이에요. | 낱말 짜임. 낱말 조각이 차례로 붙어 새 낱말이 된다(소수 + 인수 → 소인수, 소인수 + 분해 → 소인수분해) |
| 6 | 그림(시안 참조) |  | 같은 수를 여러 번 곱한 것을 ‘**거듭제곱**’이라고 해요. 2 × 2 × 2는 2³으로 나타내요. | 같은 수를 여러 번 곱한 것을 거듭제곱이라고 해요. 이 곱하기 이 곱하기 이는 이의 세제곱으로 나타내요. | 새 낱말 ‘거듭제곱’. 밑·지수라는 말은 쓰지 않는다 |
| 7 | 그림(시안 참조) |  | 소인수분해한 결과에서 같은 소인수의 곱은 거듭제곱으로 나타내요. | 소인수분해한 결과에서 같은 소인수의 곱은 거듭제곱으로 나타내요. | 2 × 2가 2²으로 바뀐다 |
