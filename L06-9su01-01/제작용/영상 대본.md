# 영상 대본 — 소인수분해

중학교 1학년 · [9수01-01] 소인수분해의 뜻을 알고, 자연수를 소인수분해 할 수 있다.

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 교과서에서 만난 낱말

위치: 2. 어휘 제시 · 화면 2

메모: 새 낱말을 수업 장면 속에서 처음 보여 준다. 이미 아는 말과 이미 아는 개념에서 출발한다는 점을 대사로 짚는다.

| 1 |  | 아미르: ‘**소인수분해**’? 처음 보는 말이야.<br>유나: ‘소수’는 알지? 소수와 관계있는 말이야. |  |  | 교실 칠판에 오늘 배울 내용이 적혀 있다. 낱말에 색이 들어온다 |
| 2 | 그림(시안 참조) | 아미르: 아, 이거! 우리 나라 학교에서 배웠어.<br>유나: 맞아. 한국어로는 **소인수분해**라고 해. |  |  | 12가 소수들의 곱으로 풀리는 모습 |

## 영상 2. 낱말 풀이: 소수에서 소인수분해까지

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 | 그림(시안 참조) |  | 1, 2, 3, 4, 6, 12 같은 수를 12의 ‘약수’라고 해요. 한국어로 ‘**인수**’라고도 해요. | 일, 이, 삼, 사, 육, 십이 같은 수를 십이의 약수라고 해요. 한국어로 인수라고도 해요. | 5차시에서 익힌 말 ‘약수’에서 시작한다. 약수를 구하는 법은 설명하지 않고, 같은 것을 가리키는 다른 이름 ‘인수’만 알려 준다 |
| 2 | 그림(시안 참조) |  | 인수 중에서 소수인 2와 3을 한국어로 12의 ‘**소인수**’라고 해요. | 인수 중에서 소수인 이와 삼을 한국어로 십이의 소인수라고 해요. | 소수 2와 3에만 색이 들어온다 |
| 3 | 그림(시안 참조) |  | 12를 소인수들만의 곱으로 나타냈어요. 이렇게 자연수를 소인수들만의 곱으로 나타내는 것을 한국어로 ‘**소인수분해**’라고 해요. | 십이를 소인수들만의 곱으로 나타냈어요. 이렇게 자연수를 소인수들만의 곱으로 나타내는 것을 한국어로 소인수분해라고 해요. | 이미 풀린 그림을 보여 준다(푸는 방법은 설명하지 않는다). 소인수 2, 2, 3에 동그라미가 차례로 생긴 뒤, 캐릭터가 나와서 낱말을 말한다 |
| 4 | 그림(시안 참조) |  | ‘**소인수**’는 ‘소수’와 ‘인수’를 합친 말이에요. ‘**소인수분해**’의 ‘분해’는 ‘나누어 놓는다’는 뜻이에요. | 소인수는 소수와 인수를 합친 말이에요. 소인수분해의 분해는 나누어 놓는다는 뜻이에요. | 낱말 짜임. 낱말 조각이 차례로 붙어 새 낱말이 된다(소수 + 인수 → 소인수, 소인수 + 분해 → 소인수분해) |
| 5 | 그림(시안 참조) |  | 2³처럼 같은 수를 여러 번 곱한 것을 한국어로 ‘**거듭제곱**’이라고 해요. | 이의 세제곱처럼 같은 수를 여러 번 곱한 것을 한국어로 거듭제곱이라고 해요. | 새 낱말 ‘거듭제곱’. 밑·지수라는 말은 쓰지 않는다. 나타내는 규칙은 설명하지 않는다 |
