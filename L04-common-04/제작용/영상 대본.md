# 영상 대본 — 문제에서 쓰는 말 ④ 설명하기

중학교 1~2학년 공통 · 공통 · 모든 단원의 문제에 쓰이는 말 (특정 성취기준에 속하지 않음)

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 문제의 끝말

위치: 1. 도입 · 화면 2

메모: 문제의 수학 내용은 알지만 끝말(지시어)을 몰라 멈추는 장면에서 시작한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 | 참여 활동(자막 전에 멈추고 묻기) |
|---:|---|---|---|---|---|---|
| 1 |  | 아미르: 답이 이미 나와 있는데, 뭘 더 써야 해?<br>유나: 왜 그런지를 문장으로 써야 해. |  |  | 교과서 문제를 크게 보여 준다 |  |
| 2 |  | 아미르: 아, ‘왜’를 쓰는 거구나.<br>유나: 맞아. ‘왜 그런지’가 **까닭**이야. |  |  | 까닭을 쓴 문장이 나타난다 |  |

## 영상 2. 낱말 풀이: 무엇을 하라는 말일까

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 | 참여 활동(자막 전에 멈추고 묻기) |
|---:|---|---|---|---|---|---|
| 1 |  |  | ‘**까닭**’은 ‘왜 그런지’예요. ‘이유’와 같은 말이에요. | 까닭은 왜 그런지예요. 이유와 같은 말이에요. |  |  |
| 2 |  |  | ‘**설명하시오**’는 왜 그런지, 어떻게 했는지를 문장으로 쓰라는 말이에요. | 설명하시오는 왜 그런지, 어떻게 했는지를 문장으로 쓰라는 말이에요. |  |  |
| 3 |  |  | ‘**말하시오**’는 답을 말이나 글로 짧게 나타내라는 말이에요. | 말하시오는 답을 말이나 글로 짧게 나타내라는 말이에요. |  |  |
| 4 | 그림(시안 참조) |  | 답을 문장으로 말했어요. | 답을 문장으로 말했어요. |  |  |

## 영상 3. 교과서 문장 속의 낱말

위치: 4. 용례 · 화면 1

메모: 용례 단계. 학교 수업에서 실제로 만나는 교과서 문장을 보여 주고, 함께 쓰이는 말(공기관계어)과 수행 도구어를 자막으로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 | 참여 활동(자막 전에 멈추고 묻기) |
|---:|---|---|---|---|---|---|
| 1 |  |  | ‘~이므로’는 까닭을 말할 때 써요. | ~이므로는 까닭을 말할 때 써요. |  |  |
| 2 |  |  | ‘~기 때문에’도 까닭을 말할 때 써요. | ~기 때문에도 까닭을 말할 때 써요. |  |  |
| 3 |  |  | ‘서술하다’는 과정을 차례대로 글로 쓴다는 말이에요. | 서술하다는 과정을 차례대로 글로 쓴다는 말이에요. |  |  |
| 4 |  |  | ‘이유’는 ‘까닭’과 같은 말이에요. | 이유는 까닭과 같은 말이에요. |  |  |
