# 영상 대본 — 문제에서 쓰는 말 ① 구하기

중학교 1~2학년 공통 · 공통 · 모든 단원의 문제에 쓰이는 말 (특정 성취기준에 속하지 않음)

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 문제의 끝말

위치: 1. 도입 · 화면 2

메모: 문제의 수학 내용은 알지만 끝말(지시어)을 몰라 멈추는 장면에서 시작한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  | 아미르: 약수는 알아. 그런데 끝에 있는 말이 무슨 뜻이지?<br>유나: ‘**구하시오**’는 답을 찾아서 쓰라는 말이야. |  |  | 교과서 문제를 크게 보여 준다. 끝말에 색이 들어온다 |
| 2 |  | 아미르: 끝이 다 ‘시오’로 끝나네.<br>유나: 맞아. 문제에서 ‘~하세요’ 대신 쓰는 말투야. |  |  | 세 낱말의 끝 ‘시오’가 함께 반짝인다 |

## 영상 2. 낱말 풀이: 무엇을 하라는 말일까

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  |  | ‘**구하시오**’는 답을 찾아서 쓰라는 말이에요. 기본형은 ‘구하다’예요. | 구하시오는 답을 찾아서 쓰라는 말이에요. 기본형은 구하다예요. |  |
| 2 | 그림(시안 참조) |  | 8의 약수를 찾아서 썼어요. 이렇게 하는 것이 ‘구하다’예요. | 8의 약수를 찾아서 썼어요. 이렇게 하는 것이 구하다예요. | 답이 하나씩 나타난다 |
| 3 |  |  | ‘**계산하시오**’는 더하기, 빼기, 곱하기, 나누기를 해서 값을 쓰라는 말이에요. | 계산하시오는 더하기, 빼기, 곱하기, 나누기를 해서 값을 쓰라는 말이에요. |  |
| 4 | 그림(시안 참조) |  | 계산해서 값 22를 얻었어요. | 계산해서 값 22를 얻었어요. | 계산 과정이 한 줄씩 나타난다 |
| 5 |  |  | ‘**푸시오**’는 문제의 답을 찾으라는 말이에요. 기본형은 ‘풀다’예요. ‘풀다’는 ‘푸시오’로 모양이 바뀌어요. | 푸시오는 문제의 답을 찾으라는 말이에요. 기본형은 풀다예요. 풀다는 푸시오로 모양이 바뀌어요. |  |
| 6 | 그림(시안 참조) |  | 문제를 풀어서 □ = 4를 얻었어요. | 문제를 풀어서 □ = 4를 얻었어요. |  |

## 영상 3. 교과서 문장 속의 낱말

위치: 4. 용례 · 화면 1

메모: 용례 단계. 학교 수업에서 실제로 만나는 교과서 문장을 보여 주고, 함께 쓰이는 말(공기관계어)과 수행 도구어를 자막으로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  |  | ‘~을/를 구하시오’로 써요. 무엇을 찾으라는지 앞의 말을 봐요. | ~을/를 구하시오로 써요. 무엇을 찾으라는지 앞의 말을 봐요. |  |
| 2 |  |  | ‘~일 때’는 조건을 말해요. ‘값’은 계산해서 나온 수예요. | ~일 때는 조건을 말해요. 값은 계산해서 나온 수예요. |  |
| 3 |  |  | ‘간단히 하다’는 식을 더 짧고 쉬운 모양으로 만든다는 말이에요. | 간단히 하다는 식을 더 짧고 쉬운 모양으로 만든다는 말이에요. |  |
| 4 |  |  | ‘각각’은 ‘하나씩 따로’라는 뜻이에요. 답을 두 번 써야 해요. | 각각은 하나씩 따로라는 뜻이에요. 답을 두 번 써야 해요. |  |
| 5 |  |  | 찾은 것을 ‘답’이라고 해요. | 찾은 것을 답이라고 해요. |  |
