# 영상 대본 — 문제에서 쓰는 말 ② 나타내기

중학교 1~2학년 공통 · 공통 · 모든 단원의 문제에 쓰이는 말 (특정 성취기준에 속하지 않음)

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 문제의 끝말

위치: 1. 도입 · 화면 2

메모: 문제의 수학 내용은 알지만 끝말(지시어)을 몰라 멈추는 장면에서 시작한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  | 아미르: 답은 7이지? 7이라고 쓰면 돼?<br>유나: 아니야. ‘**나타내시오**’는 계산하라는 말이 아니야. |  |  | 교과서 문제를 크게 보여 준다 |
| 2 | 그림(시안 참조) | 아미르: 아, 말을 식으로 바꾸어 쓰는 거구나.<br>유나: 맞아. 그게 ‘나타내다’야. |  |  | 말이 식으로 바뀌는 모습 |

## 영상 2. 낱말 풀이: 무엇을 하라는 말일까

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 아는 말과 아는 개념을 차례로 써서 새 낱말에 이른다. 낱말에 들어 있는 한자말의 뜻(예: 최대 = 가장 큰)을 풀어 주어 한국어 낱말로 받아들이게 한다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  |  | ‘**나타내시오**’는 말이나 그림을 식, 기호, 표, 그래프 같은 다른 모양으로 바꾸어 쓰라는 말이에요. | 나타내시오는 말이나 그림을 식, 기호, 표, 그래프 같은 다른 모양으로 바꾸어 쓰라는 말이에요. |  |
| 2 | 그림(시안 참조) |  | 말을 식으로 나타냈어요. 계산한 값 7을 쓰는 것이 아니에요. | 말을 식으로 나타냈어요. 계산한 값 7을 쓰는 것이 아니에요. |  |
| 3 |  |  | ‘**써넣으시오**’는 빈칸 안에 답을 쓰라는 말이에요. | 써넣으시오는 빈칸 안에 답을 쓰라는 말이에요. |  |
| 4 | 그림(시안 참조) |  | 빈칸에 4를 써넣었어요. | 빈칸에 4를 써넣었어요. |  |
| 5 |  |  | ‘**그리시오**’는 도형이나 그래프, 그림을 그리라는 말이에요. | 그리시오는 도형이나 그래프, 그림을 그리라는 말이에요. |  |

## 영상 3. 교과서 문장 속의 낱말

위치: 4. 용례 · 화면 1

메모: 용례 단계. 학교 수업에서 실제로 만나는 교과서 문장을 보여 주고, 함께 쓰이는 말(공기관계어)과 수행 도구어를 자막으로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  |  | ‘기호’는 ＋, －, ＝, ＜ 같은 표시예요. | 기호는 ＋, －, ＝, ＜ 같은 표시예요. |  |
| 2 |  |  | ‘빈칸’은 비어 있는 칸 □예요. | 빈칸은 비어 있는 칸 □예요. |  |
| 3 |  |  | ‘완성하다’는 빈 곳을 모두 채워서 끝낸다는 말이에요. | 완성하다는 빈 곳을 모두 채워서 끝낸다는 말이에요. |  |
| 4 |  |  | ‘~을 ~(으)로 나타내시오’로 써요. 무엇을, 무엇으로 바꾸는지 봐요. | ~을 ~(으)로 나타내시오로 써요. 무엇을, 무엇으로 바꾸는지 봐요. |  |
