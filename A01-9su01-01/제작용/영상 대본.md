# 영상 대본 — 소인수분해

중학교 1학년 · [9수01-01] 소인수분해의 뜻을 알고, 자연수를 소인수분해 할 수 있다.

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 교과서에서 만난 낱말

위치: 2. 어휘 제시 · 화면 2

메모: 새 낱말을 수업 장면 속에서 처음 보여 준다. 이미 아는 말(소수)과 이미 아는 개념에서 출발한다는 점을 대사로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  | 아미르: ‘**소인수분해**’? 처음 보는 말이야.<br>유나: ‘소수’는 알지? 소수와 관계있는 말이야. |  |  | 교과서 문제를 크게 보여 준다. 낱말에 색이 들어온다 |
| 2 | 그림(시안 참조) | 아미르: 아, 이거! 우리 나라 학교에서 배웠어.<br>유나: 맞아. 한국어로는 **소인수분해**라고 해. |  |  | 12가 소수들의 곱으로 풀리는 모습 |

## 영상 2. 낱말 풀이: 이미 배운 말에서 소인수분해까지

위치: 3. 정의 · 화면 1

메모: 개념을 새로 가르치지 않는다. 이미 배운 말(약수 → 소수 → 지수)을 차례로 써서 새 낱말 두 개에 이른다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 | 그림(시안 참조) |  | 2, 3, 4, 6은 12의 약수예요. 약수를 ‘인수’라고도 해요. | 이, 삼, 사, 육은 십이의 약수예요. 약수를 인수라고도 해요. | 이미 배운 말 ‘약수’에서 시작한다 |
| 2 | 그림(시안 참조) |  | 인수 중에서 소수인 2와 3을 12의 ‘**소인수**’라고 해요. | 인수 중에서 소수인 이와 삼을 십이의 소인수라고 해요. | 소수 2와 3에만 색이 들어온다. 소인수 = 소수인 인수 |
| 3 | 그림(시안 참조) |  | 12를 소인수들만의 곱으로 나타냈어요. | 십이를 소인수들만의 곱으로 나타냈어요. | 소인수 2, 2, 3에 동그라미가 차례로 생긴다 |
| 4 | 그림(시안 참조) |  | 자연수를 소인수들만의 곱으로 나타내는 것을 ‘**소인수분해**’라고 해요. | 자연수를 소인수들만의 곱으로 나타내는 것을 소인수분해라고 해요. | 캐릭터가 나와서 뜻을 말한다 |
| 5 | 그림(시안 참조) |  | 같은 소인수의 곱은 지수를 사용하여 거듭제곱으로 나타내요. | 같은 소인수의 곱은 지수를 사용하여 거듭제곱으로 나타내요. | 이미 배운 말 ‘지수’, ‘거듭제곱’을 다시 쓴다 |

## 영상 3. 교과서 문장 속의 낱말

위치: 4. 용례 · 화면 1

메모: 용례 단계. 학교 수업에서 실제로 만나는 교과서 문장을 보여 주고, 함께 쓰이는 말과 수행 도구어를 자막으로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  |  | ‘~의 소인수’라고 써요. ‘모두 구하시오’는 하나도 빼지 말고 다 찾으라는 말이에요. | 다음 수의 소인수를 모두 구하시오. |  |
| 2 |  |  | ‘~을 소인수분해하시오’는 소인수들만의 곱으로 나타내라는 말이에요. | 다음 수를 소인수분해하시오. |  |
| 3 |  |  | ‘소인수분해하면 ~이다’로 결과를 말해요. | 십팔을 소인수분해하면 이 곱하기 삼의 제곱이다. |  |
| 4 |  |  | ‘소인수분해를 이용하여’는 그다음 단원에서 자주 나와요. | 소인수분해를 이용하여 두 수의 최대공약수를 구하시오. |  |
