# 영상 대본 — 소인수분해

중학교 1학년 · [9수01-01] 소인수분해의 뜻을 알고, 자연수를 소인수분해 할 수 있다.

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 3. 교과서 문장 속의 소인수분해

위치: 4. 용례 · 화면 1

메모: 용례 단계. 교과서 문장을 그대로 보여 주고, 함께 쓰이는 말(공기관계어)과 수행 도구어를 자막으로 짚는다: ~을/를 소인수분해하다, 소수들의 곱으로 나타내다, 소인수분해하면 ~이다, 소인수분해를 이용하여 ~을 구하다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  |  | ‘~을 소인수분해하시오’는 소수들의 곱으로 나타내라는 말이에요. | 다음 수를 소인수분해하시오. |  |
| 2 |  |  | ‘나타내시오’는 식으로 써서 보여 달라는 말이에요. 12 = 2² × 3 | 십이를 소수들의 곱으로 나타내시오. |  |
| 3 |  |  | ‘소인수분해하면 ~이다’로 결과를 말해요. | 십팔을 소인수분해하면 이 곱하기 삼의 제곱이다. |  |
| 4 |  |  | ‘소인수분해를 이용하여’는 다음 단원에서 자주 나와요. | 소인수분해를 이용하여 두 수의 최대공약수를 구하시오. |  |
