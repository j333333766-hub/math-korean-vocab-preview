중학교 1학년 · [9수01-01] 소인수분해의 뜻을 알고, 자연수를 소인수분해 할 수 있다.

등장인물: 아미르, 유나 (임시 이름과 임시 그림. 실제 캐릭터로 바꾼다.)

낱말 앞뒤의 `**`는 화면에서 색으로 강조할 말이다. 그림은 시안(index.html)의 같은 컷을 본다.

## 영상 1. 수업 장면: 교과서에서 만난 낱말

위치: 2. 어휘 제시 · 화면 2

메모: 낱말을 수업 장면 속에서 처음 보여 준다. 뜻은 아직 설명하지 않는다.

|---:|---|---|---|---|---|
| 1 |  | 아미르: ‘**소수**’? 2, 11 같은 수를 말하는 건가?<br>유나: 응, 맞아. 약수가 1과 자기 자신뿐인 수야. |  |  | 교과서 문제를 크게 보여 준다. 낱말에 색이 들어온다 |

## 영상 2. 낱말 풀이: 소수, 지수, 소인수분해

위치: 3. 정의 · 화면 4

메모: 개념을 새로 가르치지 않는다. 이미 아는 내용을 짧게 보여 주고 한국어 낱말을 붙인다. 낱말마다 2컷.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 | 그림(시안 참조) |  | 7의 약수는 1과 7뿐이에요. 이런 수를 ‘**소수**’라고 해요. | 칠의 약수는 일과 칠뿐이에요. 이런 수를 소수라고 해요. |  |
| 2 |  |  | 0.5 같은 수도 ‘소수’라고 써요. 글자는 같지만 다른 말이에요. | 영 점 오 같은 수도 소수라고 써요. 글자는 같지만 다른 말이에요. | 위쪽(오늘의 낱말)에만 색이 들어온다. 읽는 소리가 다르다: 위 [소쑤], 아래 [소:수] |
| 3 | 그림(시안 참조) |  | 2를 3번 곱했어요. 2³은 2의 거듭제곱이에요. | 이를 세 번 곱했어요. 이의 세제곱은 이의 거듭제곱이에요. | 2 × 2 × 2가 2³으로 모인다 |
| 4 | 그림(시안 참조) |  | 곱한 횟수를 나타내는 작은 수 3을 ‘**지수**’라고 해요. 2는 ‘밑’이에요. | 곱한 횟수를 나타내는 작은 수 삼을 지수라고 해요. 이는 밑이에요. | 지수 3에 색이 들어오고 ‘지수’, ‘밑’ 표시가 나타난다 |
| 5 | 그림(시안 참조) |  | 12를 소수들의 곱으로 나타냈어요. 2와 3은 12의 소인수예요. | 십이를 소수들의 곱으로 나타냈어요. 이와 삼은 십이의 소인수예요. | 소수 2, 2, 3에 동그라미가 차례로 생긴다 |
| 6 | 그림(시안 참조) |  | 자연수를 소수들의 곱으로 나타내는 것을 ‘**소인수분해**’라고 해요. 같은 소수의 곱은 지수를 사용하여 써요. | 자연수를 소수들의 곱으로 나타내는 것을 소인수분해라고 해요. 같은 소수의 곱은 지수를 사용하여 써요. | 2 × 2가 2²으로 바뀐다. 캐릭터가 나와서 뜻을 말한다 |

## 영상 3. 교과서 문장 속의 낱말

위치: 4. 용례 · 화면 1

메모: 용례 단계. 교과서 문장을 그대로 보여 주고, 함께 쓰이는 말(공기관계어)과 수행 도구어를 자막으로 짚는다.

| 컷 | 화면 | 대사 | 자막 | 내레이션 | 연출 |
|---:|---|---|---|---|---|
| 1 |  |  | ‘모두 고르시오’는 맞는 것을 하나도 빼지 말고 다 찾으라는 말이에요. | 다음 수 중에서 소수를 모두 고르시오. |  |
| 2 |  |  | ‘밑과 지수’는 함께 자주 써요. 밑은 2, 지수는 5예요. | 이의 다섯제곱의 밑과 지수를 각각 말하시오. |  |
| 3 |  |  | ‘나타내시오’는 식으로 써서 보여 달라는 말이에요. 12 = 2² × 3 | 십이를 소인수분해하고, 지수를 사용하여 나타내시오. |  |
| 4 |  |  | ‘소인수분해하면 ~이다’로 결과를 말해요. | 십팔을 소인수분해하면 이 곱하기 삼의 제곱이다. |  |
| 5 |  |  | ‘소인수분해를 이용하여’는 다음 단원에서 자주 나와요. | 소인수분해를 이용하여 두 수의 최대공약수를 구하시오. |  |
